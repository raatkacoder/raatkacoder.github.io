# 🔥 Epic Meme Generator

The ultimate meme generator for creating viral content! Built with vanilla JavaScript, HTML5 Canvas, and pure awesomeness.

## ✨ Features

- 🎭 100+ Popular meme templates
- ✏️ Custom text with multiple styles
- 🎨 Color customization
- 📤 Upload your own images
- ⬇️ Download memes in high quality
- 📱 Fully responsive design
- 🎲 Random meme generator
- 💾 Tracks your meme creation count
- 🚀 Lightning fast & no backend needed

## 🚀 Live Demo

Deploy to GitHub Pages:

1. Fork this repository
2. Go to Settings > Pages
3. Select main branch
4. Your site will be live at `https://yourusername.github.io/meme-generator`

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/meme-generator.git

# Navigate to directory
cd meme-generator

# Open index.html in your browser
# Or use a local server:
python -m http.server 8000
# Then visit http://localhost:8000
